# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-04-17

### Added

- Initial release of react-reachability
- Network reachability detection using Web Workers for non-blocking operation
- React hook `useReachability` for seamless React integration
- Vanilla JavaScript API for framework-agnostic usage
- SSR-safe implementation with main-thread fallback
- Configurable polling intervals, timeouts, and retry logic
- Full TypeScript support with comprehensive type definitions
- Comprehensive test suite using Vitest with coverage reporting
- Example application demonstrating React and vanilla JS usage
- Build system with tsup for dual CJS/ESM outputs
- ESLint and Prettier for code quality
